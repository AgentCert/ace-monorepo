  kubectl port-forward -n {{ include "ace.namespace" . }} svc/web 2001:2001           → http://localhost:2001
  kubectl port-forward -n {{ include "ace.namespace" . }} svc/langfuse-web 4000:3000  → http://localhost:4000

Check pod status:
  kubectl get pods -n {{ include "ace.namespace" . }}

View logs:
  kubectl logs -n {{ include "ace.namespace" . }} -l app=graphql --tail=50 -f

Upgrade the release (setup.sh writes both values files; re-run it after editing .env):
  helm upgrade --install ace deploy/helm/ace -n {{ include "ace.namespace" . }} \
    -f deploy/helm/ace/values-env.yaml -f deploy/helm/ace/values-platform.yaml \
    --timeout 10m

Rollback to previous version:
  helm rollback ace -n {{ include "ace.namespace" . }}

Uninstall (keeps PVCs by default):
  helm uninstall ace -n {{ include "ace.namespace" . }}
