# ACE image inventory — every container image the stack needs, in one place.
#
# Read by:
#   scripts/check-registry-images.sh   is every image present in IMAGE_REGISTRY?
#   scripts/mirror-images.sh           copies the "mirror" rows into IMAGE_REGISTRY
#   scripts/build-and-push.sh          builds and pushes the "build" rows
#
# Naming rule (scripts/lib/registry.sh): an image is always written here by its
# normal public name. When IMAGE_REGISTRY is set, the registry copy lives at
# <IMAGE_REGISTRY>/<public name>, e.g.
#   mongo:5                       -> infyartifactory.jfrog.io/docker-local/mongo:5
#   quay.io/containers/x:v1       -> infyartifactory.jfrog.io/docker-local/quay.io/containers/x:v1
# When IMAGE_REGISTRY is empty, images come from frozen Docker Hub copies under
# IMAGE_MIRROR_NAMESPACE (default agentcert), with flat names because Docker Hub
# repos cannot nest:
#   mongo:5                       -> agentcert/mongo:5
#   quay.io/containers/x:v1       -> agentcert/containers-x:v1
# (IMAGE_MIRROR_NAMESPACE=none uses the upstream name as-is.)
#
# Columns, separated by "|":
#   kind     build  = ACE-owned, built from this checkout by build-and-push.sh
#            mirror = third-party, copied unchanged by mirror-images.sh
#   group    platform | infra | workflow | agents | apps | build-base | local
#   image    public name with tag
#   context  build rows only: build context, relative to the repo root
#   recipe   build rows only: Dockerfile path relative to the context, or a
#            special recipe (hub-bundle). The Dockerfile may sit outside the
#            context (compose/web/Dockerfile).
#   flags    optional = not needed on the default AKS path; skipped unless
#            --include-optional is passed
#
# When you add an image anywhere in the stack, add it here too.
#
# Deliberately NOT listed (never mirror these):
#   quay.io/it-bench/hello-bench-invalid:1.0.0   INVALID_IMAGE — the fault needs the pull to fail
#   arm64v8/busybox:1.36.1-musl                  INVALID_ARCH_IMAGE — same reason
