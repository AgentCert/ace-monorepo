## Implementation Tasks

### Task 1: Extract Secret Values from Experiment Save

**Objective:** When `saveChaosExperiment` is called, find any agent nodes in the experiment that have `type: secret` inputs. Collect those values and create/update the K8s Secret.

**File to Modify:** `pkg/chaos_experiment/` service (wherever `saveChaosExperiment` business logic lives)

**Secret creation hook (call after experiment document is saved):**

```go
func (s *experimentService) createOrUpdateAgentSecret(
    ctx context.Context,
    experimentID string,
    agentName    string,
    secretInputs map[string]string,  // key → value from the form
) error {
    secretName := "ace-agent-secret-" + experimentID
    data := make(map[string][]byte, len(secretInputs))
    for k, v := range secretInputs {
        data[k] = []byte(v)
    }
    return k8s_secret.CreateOrUpdateSecret(ctx, s.k8sClient, secretName, "litmus", data)
}
```

**Where to get `secretInputs`:** The `saveChaosExperiment` GraphQL input carries the agent configuration. Agent inputs of `type: secret` are passed by the frontend in the experiment save payload. Look for the agent configuration section in the `SaveChaosExperimentRequest` and extract `type: secret` fields.

**Important:** Secret values must NEVER be logged. Use `logrus.WithField("secretCount", len(data))` not `logrus.WithField("secretKeys", ...)`.

### Task 4: Update `SaveChaosExperimentRequest` to Carry Secret Inputs

**Objective:** The frontend must pass secret values when saving an experiment. They go directly into the K8s Secret and never into the Argo Workflow YAML.

**File to Modify:** `graphql/definitions/shared/chaos_experiment.graphqls` (if needed)

Add to the experiment save input:

```graphql

  key:   String!

}

  agentName:     String!

}

```

**Frontend change (in Stage 5 Step 7 or experiment form):** Pass agent secret values via `agentConfig.secretInputs` in `saveChaosExperiment`. The values are submitted over TLS/HTTPS → stored only in K8s Secret → never in Argo YAML.
