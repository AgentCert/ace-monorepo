## Implementation Tasks

### Task 1: Resolve `litellmUpstream` at Experiment Submit Time

**Objective:** When a user submits an experiment (not saves — submits/runs), the workflow needs to know the LiteLLM upstream URL for the agent's model config.

**Location:** Wherever the Argo workflow is submitted (look for the `runChaosExperiment` or equivalent mutation).

**Resolution logic:**

```go
func (s *experimentService) resolveLiteLLMUpstream(ctx context.Context, projectID, agentName string) (string, error) {
    // 1. Get agent from registry
    agent, err := s.agentRegistry.GetAgentByProjectAndName(ctx, projectID, agentName)
    if err != nil {
        return "", err
    }

    // 2. If agent has no LLM config or is not LLM-dependent, return empty string
    if agent.LLMConfig == nil || !agent.LLMConfig.LLMDependent {
        return "", nil
    }

    // 3. Look up the model config by alias
    configRef := agent.LLMConfig.ConfigRef
    if configRef == "" {
        return "", fmt.Errorf("agent %s has llmDependent:true but no configRef", agentName)
    }

    modelConfig, err := s.modelLibrary.GetModelConfig(ctx, projectID, configRef)
    if err != nil {
        return "", fmt.Errorf("model config '%s' not found: %w", configRef, err)
    }

    // 4. Construct LiteLLM upstream URL from the deploy ID
    // Convention: http://<litellm-svc>.<litellm-ns>.svc.cluster.local:<port>/v1
    litellmBase := os.Getenv("LITELLM_PROXY_URL") // e.g., "http://litellm.litmus.svc.cluster.local:4000"
    upstream := litellmBase + "/v1"

    // The deploy ID is embedded as metadata; the sidecar routes to the alias-named deployment
    // LiteLLM routes by model_name (alias); the upstream is the same for all models
    _ = modelConfig.LiteLLMDeployID // used for audit; not in the URL directly
    return upstream, nil
}
```

The `litellmUpstream` value is added as an Argo workflow parameter:

```yaml
arguments:
  parameters:
    - name: litellmUpstream
      value: "http://litellm.litmus.svc.cluster.local:4000/v1"
```

### Task 2: Wire Context Injections into install-agent Step Args

**Objective:** For every entry in the agent's `contextInjection[]`, generate a `--set` arg in the install-agent step. The `{{workflow.xxx}}` references are Argo template variables — pass them as literal strings; Argo resolves them before the container starts.

**Location:** install-agent step generation in the hydration pipeline

**Example generated YAML:**

```yaml
- name: install-agent
  container:
    image: agentcert/agentcert-install-agent:latest
    args:
      - "--folder=flash-agent"
      - "--namespace={{workflow.parameters.appNamespace}}"
      - "--set=agent.secretRef=ace-agent-secret-{{workflow.parameters.experimentID}}"
      - "--set=agent.notifyId={{workflow.name}}"
      - "--set=agent.workflowUid={{workflow.uid}}"
      - "--set=sidecar.upstream={{workflow.parameters.litellmUpstream}}"
      - "--set=agent.config.SCAN_INTERVAL=30"   # from non-secret user inputs
      - "--wait"
      - "--timeout=20m"
```

**Code that generates this:**

```go
func buildInstallAgentArgs(agent *AgentDocument, experimentID string) []string {
    args := []string{
        "--folder=" + agent.Install.Folder,  // or image for generic-wrapper
        "--namespace={{workflow.parameters.appNamespace}}",
        "--set=agent.secretRef=ace-agent-secret-" + experimentID,
    }

    // Add context injections from agent spec
    for _, ci := range agent.ContextInject {
        // Source is an Argo template expression — pass as-is
        args = append(args, fmt.Sprintf("--set=%s=%s", ci.HelmPath, ci.Source))
    }

    // Add non-secret user inputs as --set args
    // (secret inputs are in the K8s Secret; not passed as --set)
    for _, input := range agent.Inputs {
        if input.Type != "secret" {
            // value comes from the experiment's saved agent config
            args = append(args, fmt.Sprintf("--set=%s=%s", input.HelmPath, getInputValue(input)))
        }
    }

    args = append(args, "--wait", "--timeout="+agent.Install.Timeout)
    return args
}
```

## Common Issues and Solutions

### Issue 1: Argo rejects `{{workflow.parameters.xxx}}` reference
**Symptom:** Argo validation fails with "parameter not defined"  
**Solution:** Ensure the parameter is declared in `spec.arguments.parameters` with a default or a value.

### Issue 2: sidecar.upstream is empty for rule-based agents
**Symptom:** `sidecar.upstream` `--set` arg is empty string  
**Solution:** If `llmDependent: false`, skip the `sidecar.upstream` context injection. The sidecar won't start for rule-based agents.
